## 完成标志

1. 收藏页三处计数（已保存 / 集合 / 标签）与标签页的未关联计数，在用户动作导致数值变化时做一次数字滚动。
2. 首次挂载与 `—` 切换到数字时不播放动画。
3. 列表行点击进入详情时，标题通过 View Transitions 连续过渡；浏览器不支持时直接跳转。
4. 字面量时长（`150ms`、`140ms`）全部改为 token；正文区域无 `transform`。
5. reduced-motion 下数字直接替换，视图过渡时长压到 0.01ms，布局不变。

## 数据流与判断

- `ArchiveCounter` 用 `watch(() => props.value)` 拿到 `previous` 与 `next`。只有两者都是数字且不是 reduced-motion 时才滚动。
- 数字用纵向堆叠的 `.digit-reel`，每位通过 `translateY(-Nem)` 定位；滚动只改 `transform`，宽度由 `.num`（tabular-nums）保证。
- `openLink(link, navigate, event)` 只在无修饰键的左键点击、且浏览器支持 `document.startViewTransition` 时走过渡；其余情况交给 `router-link` 原生行为。
- `base.css` 中 `::view-transition-*` 的 reduced-motion 规则是独立块，因为全局 `*` 选择器不覆盖伪元素。

## 动效规格

| 项目 | 数字滚动（I3） | 视图过渡（I4） |
|---|---|---|
| 触发 | 用户动作导致数值变化 | 点击收藏行进入详情 |
| 时长 / 缓动 | 220ms（`ROLL_DURATION_SECONDS = 0.22`）/ `cubic-bezier(0.2, 0.8, 0.2, 1)` | group 220ms；root 旧/新 140ms；同一缓动 |
| 起止状态 | 旧位数字滚到新位，只滚一次 | 列表标题位置 → 详情标题位置 |
| 不播放 | 首次挂载；`—` 与数字之间切换；reduced-motion | 修饰键点击；不支持 API；reduced-motion |
| reduced-motion | 直接显示新值 | 伪元素动画时长 0.01ms |
| 传达的信息 | 数量已更新 | 同一篇收藏在列表与详情之间的位置关系 |

## 布局稳定

- 计数器的根节点保持 `inline-flex`，数字宽度由 tabular-nums 固定。
- 正文区域（`.readable-text`）没有 `transform`、`scale` 或视差；审计通过阅读源码完成，未用浏览器测量。

## 收口（I5）

- `TagsView.vue` 的 `tbody tr` 背景过渡：`150ms ease` → `var(--motion-fast) var(--ease-out)`。

- `.metric span` 改为 `.metric > span`，避免把计数器根节点当作普通文字样式覆盖。
- 第三方依赖登记在 `frontend/THIRD_PARTY_NOTICES.md`：motion-v 2.11.1、framer-motion 14.9.1、motion-dom 14.9.1、motion-utils 14.7.0，均为 MIT。
