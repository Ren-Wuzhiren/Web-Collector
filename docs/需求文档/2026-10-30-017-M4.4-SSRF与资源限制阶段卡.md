### 二级阶段 M4.4：让抓取不至于拖垮服务器

**一句话**：在真实浏览器抓取前后增加 SSRF 拦截、重定向复检、超时和响应大小限制。
**完成标志**：localhost、私网、云元数据和 DNS 解析到内部地址的 URL 被拒绝；重定向每跳复检；超时和超大 HTML 不会无限占用资源。
**实施状态（2026-11-02）**：生产实现与自动化验收完成；全量测试 324 项通过、4 跳过。学习验收待用户回答。
**预计时长**：一次实现会话　**依赖**：M4.3 已完成

---

#### 1. 涉及技术栈（为什么是它）

| 技术/组件 | 用在哪 | 为什么选它 | 备选 & 不选的理由 |
|---|---|---|---|
| `java.net.URI` / `InetAddress` | 解析 URL、解析全部 A/AAAA 地址 | JDK 自带，能在真正连接前做主机和 IP 检查 | 只检查字符串黑名单会漏掉 DNS 指向内网的域名 |
| Java `HttpClient` | 安全预检、手动重定向和响应大小限制 | 能逐跳检查 Location 并限制读取字节数 | 直接把 URL 交给 Playwright，无法在每次重定向前复检 |
| Playwright route | 浏览器子资源请求拦截 | 防止主页面安全但脚本把浏览器带到内网 | 只校验主 URL 无法覆盖 iframe、图片和脚本请求 |

#### 2. 原理讲解（不用它会怎样）

- **SSRF 防护**：禁止回环、私网、链路本地、组播、保留地址和云元数据地址。不用它：用户输入一个内部 URL，服务器会替用户访问内网服务。
- **DNS 全地址检查**：主机名可能解析出多个 A/AAAA，任一地址危险就拒绝。不用它：只检查第一个地址会留下 DNS 轮换绕过。
- **重定向复检**：每个 3xx 的 Location 都重新解析和检查。不用它：公开 URL 可以 302 到 localhost，初始检查会被绕过。
- **资源限制**：导航超时、总超时、HTML 最大字节数分别限制。不用它：慢响应或无限大页面会占住浏览器、线程和内存。

#### 3. 架构讲解（这一步在整体里占哪个位置）

- **分层位置**：`BrowserHtmlCapture → SafeUrlPolicy → HttpClient预检/重定向 → Playwright route → 文件输出`。
- **数据流向**：

```text
输入 URL
  → 解析 scheme/host/userinfo
  → DNS 解析全部 A/AAAA 并拒绝危险网段
  → HttpClient 手动跟随重定向，每一跳重新校验
  → Playwright 打开已校验 URL
  → route 拦截子资源请求，再次执行 SafeUrlPolicy
  → 导航/总超时与 HTML 大小限制
  → 输出 HTML/PDF/截图
```

- **改动边界**：新增 URL 安全策略、受限 HTTP 预检、Playwright 子资源拦截和限制异常；不新增 asset 表、搜索、HTTP 接口或任务状态策略。
- **为什么放这层**：安全策略属于采集基础设施，不能让 Controller 或 `CaptureJobService` 各自复制一份判断。

#### 4. 步骤（每步都能看到结果）

| # | 做什么 | 完成后能观察到什么 |
|---|---|---|
| 1 | 定义安全 URL 策略和错误类型 | localhost、私网、userinfo 等输入有稳定拒绝结果 |
| 2 | 实现 DNS/IP 检查 | 任一危险 A/AAAA 地址都会拒绝 |
| 3 | 实现逐跳重定向预检 | 公开地址跳到内网时被拦截 |
| 4 | 接入 Playwright route | 子资源请求不会绕过安全策略 |
| 5 | 增加超时和大小限制 | 慢页面和超大 HTML 在边界内失败 |
| 6 | 编写本地 HTTP/DNS 测试 | 不依赖真实公网即可验证关键安全路径 |

#### 5. 重难语法讲解

- **`InetAddress` 地址分类**：不能只用 `isSiteLocalAddress()`；需要覆盖 loopback、link-local、multicast、any-local、私网和保留网段。
- **HttpClient 手动重定向**：使用 `Redirect.NEVER`，读取 3xx 的 `Location` 后重新调用安全策略，最多允许固定跳数。
- **Playwright `route`**：每个子请求先判断 URL；危险请求 `abort()`，允许请求 `continue_()`；不要把 route 拦截逻辑写进任务状态 Service。

##### `backend/src/main/java/com/webcollector/capture/security/SafeUrlPolicy.java`

```java
package com.webcollector.capture.security;

import java.net.Inet6Address;
import java.net.InetAddress;
import java.net.URI;
import java.net.UnknownHostException;
import java.util.List;
import java.util.Locale;

/**
 * SSRF URL 安全策略。
 *
 * [M4.4] 只负责判断一个 URI 是否允许被服务端访问，
 * 不负责发起 HTTP 请求，也不负责 Playwright 生命周期。
 */
public class SafeUrlPolicy {

    private static final String METADATA_HOST = "169.254.169.254";

    public URI validateAndResolve(String rawUrl) {
        if (rawUrl == null || rawUrl.isBlank()) {
            throw new UnsafeUrlException("URL 不能为空");
        }

        try {
            URI uri = URI.create(rawUrl.strip()).parseServerAuthority();
            validate(uri);
            return uri;
        } catch (IllegalArgumentException exception) {
            if (exception instanceof UnsafeUrlException unsafe) {
                throw unsafe;
            }
            throw new UnsafeUrlException("URL 格式不合法", exception);
        }
    }

    public void validate(URI uri) {
        if (uri == null) {
            throw new UnsafeUrlException("URL 不能为空");
        }

        String scheme = uri.getScheme();
        if (scheme == null
                || !(scheme.equalsIgnoreCase("http")
                || scheme.equalsIgnoreCase("https"))) {
            throw new UnsafeUrlException("仅允许 HTTP/HTTPS URL");
        }

        if (uri.getRawUserInfo() != null) {
            throw new UnsafeUrlException("不允许 URL userinfo");
        }

        String host = uri.getHost();
        if (host == null || host.isBlank()) {
            throw new UnsafeUrlException("URL 主机不合法");
        }

        String normalizedHost = host.toLowerCase(Locale.ROOT);
        if (normalizedHost.equals("localhost")
                || normalizedHost.endsWith(".localhost")
                || normalizedHost.equals(METADATA_HOST)
                || isSingleLabelHost(normalizedHost)) {
            throw new UnsafeUrlException("URL 主机不安全: " + host);
        }

        try {
            List<InetAddress> addresses = List.of(
                    InetAddress.getAllByName(normalizedHost)
            );

            for (InetAddress address : addresses) {
                if (isUnsafeAddress(address)) {
                    throw new UnsafeUrlException(
                            "URL 解析到不安全地址: " + address.getHostAddress()
                    );
                }
            }
        } catch (UnknownHostException exception) {
            throw new UnsafeUrlException("URL 主机无法解析: " + host, exception);
        }
    }

    private boolean isSingleLabelHost(String host) {
        return !host.contains(".") && !host.contains(":");
    }

    private boolean isUnsafeAddress(InetAddress address) {
        if (address.isAnyLocalAddress()
                || address.isLoopbackAddress()
                || address.isLinkLocalAddress()
                || address.isMulticastAddress()
                || address.isSiteLocalAddress()) {
            return true;
        }

        byte[] bytes = address.getAddress();
        if (bytes.length == 4) {
            return isUnsafeIpv4(bytes);
        }

        if (address instanceof Inet6Address ipv6) {
            return isUnsafeIpv6(ipv6);
        }

        return false;
    }

    private boolean isUnsafeIpv4(byte[] bytes) {
        int first = Byte.toUnsignedInt(bytes[0]);
        int second = Byte.toUnsignedInt(bytes[1]);

        return first == 0
                || first == 10
                || (first == 100 && second >= 64 && second <= 127)
                || (first == 127)
                || (first == 169 && second == 254)
                || (first == 172 && second >= 16 && second <= 31)
                || (first == 192 && second == 0)
                || (first == 192 && second == 168)
                || (first == 198 && (second == 18 || second == 19))
                || (first == 198 && second == 51)
                || (first == 203 && second == 0)
                || (first >= 224);
    }

    private boolean isUnsafeIpv6(Inet6Address address) {
        byte[] bytes = address.getAddress();
        int first = Byte.toUnsignedInt(bytes[0]);
        int second = Byte.toUnsignedInt(bytes[1]);

        // fc00::/7 unique local, fe80::/10 link local,
        // ff00::/8 multicast and 2001:db8::/32 documentation range.
        return (first & 0xFE) == 0xFC
                || (first == 0xFE && (second & 0xC0) == 0x80)
                || first == 0xFF
                || (first == 0x20
                && second == 0x01
                && bytes[2] == 0x0D
                && bytes[3] == (byte) 0xB8);
    }
}
```

##### `backend/src/main/java/com/webcollector/capture/security/SafeNavigationClient.java`

```java
package com.webcollector.capture.security;

import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;

/** 逐跳校验重定向并限制预检响应大小。 */
public class SafeNavigationClient {

    private static final int MAX_REDIRECTS = 10;
    private static final long MAX_RESPONSE_BYTES = 10 * 1024 * 1024;
    private static final Duration REQUEST_TIMEOUT = Duration.ofSeconds(30);

    private final SafeUrlPolicy safeUrlPolicy;
    private final HttpClient httpClient;

    public SafeNavigationClient(SafeUrlPolicy safeUrlPolicy) {
        this.safeUrlPolicy = safeUrlPolicy;
        this.httpClient = HttpClient.newBuilder()
                .followRedirects(HttpClient.Redirect.NEVER)
                .connectTimeout(REQUEST_TIMEOUT)
                .build();
    }

    public URI validateRedirectChain(String rawUrl) {
        URI current = safeUrlPolicy.validateAndResolve(rawUrl);

        for (int redirect = 0; redirect <= MAX_REDIRECTS; redirect++) {
            HttpRequest request = HttpRequest.newBuilder(current)
                    .timeout(REQUEST_TIMEOUT)
                    .GET()
                    .build();

            HttpResponse<byte[]> response;
            try {
                response = httpClient.send(
                        request,
                        HttpResponse.BodyHandlers.ofByteArray()
                );
            } catch (IOException exception) {
                throw new NavigationLimitException(
                        "URL 预检失败: " + current,
                        exception
                );
            } catch (InterruptedException exception) {
                Thread.currentThread().interrupt();
                throw new NavigationLimitException(
                        "URL 预检被中断: " + current,
                        exception
                );
            }

            if (response.body().length > MAX_RESPONSE_BYTES) {
                throw new NavigationLimitException(
                        "URL 响应超过大小限制: " + current
                );
            }

            int status = response.statusCode();
            if (status < 300 || status >= 400) {
                return current;
            }

            if (redirect == MAX_REDIRECTS) {
                throw new NavigationLimitException("重定向次数超过限制");
            }

            String location = response.headers()
                    .firstValue("Location")
                    .orElseThrow(() -> new NavigationLimitException(
                            "重定向缺少 Location"
                    ));

            URI next = current.resolve(location);
            safeUrlPolicy.validate(next);
            current = next;
        }

        throw new NavigationLimitException("重定向检查失败");
    }
}
```

##### `backend/src/main/java/com/webcollector/capture/browser/PlaywrightBrowserHtmlCapture.java`

```java
package com.webcollector.capture.browser;

import com.microsoft.playwright.Browser;
import com.microsoft.playwright.BrowserContext;
import com.microsoft.playwright.BrowserType;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.Playwright;
import com.microsoft.playwright.Route;
import com.webcollector.capture.security.SafeNavigationClient;
import com.webcollector.capture.security.SafeUrlPolicy;
import org.springframework.stereotype.Service;

import java.net.URI;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

/** M4.4 安全与资源限制接入点。 */
@Service
public class PlaywrightBrowserHtmlCapture {

    private static final int NAVIGATION_TIMEOUT_MILLIS = 30_000;
    private static final long MAX_HTML_BYTES = 10 * 1024 * 1024;

    private final SafeUrlPolicy safeUrlPolicy;
    private final SafeNavigationClient safeNavigationClient;

    public PlaywrightBrowserHtmlCapture() {
        this.safeUrlPolicy = new SafeUrlPolicy();
        this.safeNavigationClient = new SafeNavigationClient(safeUrlPolicy);
    }

    public Path capture(String url, Path outputPath) {
        URI safeUrl = safeNavigationClient.validateRedirectChain(url);

        try (
                Playwright playwright = Playwright.create();
                Browser browser = playwright.chromium().launch(
                        new BrowserType.LaunchOptions().setHeadless(true)
                );
                BrowserContext context = browser.newContext();
                Page page = context.newPage()
        ) {
            context.setDefaultTimeout(NAVIGATION_TIMEOUT_MILLIS);
            page.route("**/*", route -> handleSubresource(route));
            page.navigate(safeUrl.toString());

            String html = page.content();
            long htmlBytes = html.getBytes(StandardCharsets.UTF_8).length;
            if (htmlBytes > MAX_HTML_BYTES) {
                throw new NavigationLimitException(
                        "渲染后的 HTML 超过大小限制"
                );
            }

            Path target = outputPath.toAbsolutePath().normalize();
            Path parent = target.getParent();
            if (parent != null) {
                Files.createDirectories(parent);
            }
            Files.writeString(target, html, StandardCharsets.UTF_8);
            return target;
        } catch (NavigationLimitException exception) {
            throw exception;
        } catch (Exception exception) {
            throw new IllegalStateException(
                    "安全网页捕获失败: " + url,
                    exception
            );
        }
    }

    private void handleSubresource(Route route) {
        try {
            safeUrlPolicy.validateAndResolve(route.request().url());
            route.resume();
        } catch (RuntimeException exception) {
            route.abort();
        }
    }
}
```

#### 8. 坑（会怎么错，不是要注意什么）

- ❌ 只拦截 `localhost` 字符串 → 域名解析到内网时仍可 SSRF → 检查全部 A/AAAA。
- ❌ 只检查初始 URL → 302 可跳到内网 → 每个 Location 重新校验。
- ❌ 只校验主文档 → 页面脚本可请求内网 → Playwright route 拦截所有子资源。
- ❌ 用 `readAllBytes` 后再判断大小 → 超大响应已经占满内存 → 流式读取时超过上限立即中止。
- ❌ 把所有异常都转成普通 500 → 用户无法区分不安全 URL 与采集失败 → 使用稳定的安全/限制异常类型。
