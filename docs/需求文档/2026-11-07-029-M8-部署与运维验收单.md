## 6. 未验证与后续边界

- 公网域名、HTTPS、反向代理链和真实公网攻击面尚未验收。
- 30 个真实网页的成功率、耗时和失败分布属于 M9.1。
- 本地 Docker 发布端口可能让多个宿主客户端共享 Nginx 观察地址；本轮已验证客户端伪造 XFF 无法绕过。
- M9 交付材料、简历描述和最终项目复盘未开始。

## 7. 失败边界

- Docker Registry 不可达时保持“受阻”，不以配置文件存在代替构建证据。
- 数据库有记录但资产缺失时不得判定备份恢复通过。
- 限流超限必须返回 429 与正整数 `Retry-After`。
- Redis 不可用时必须返回 503，不能静默放行。
- 不可信直连来源提供的 `X-Real-IP` 或 `X-Forwarded-For` 必须被忽略。
- 摘要日志不得包含完整 URL、正文、文件路径或原始异常。

M8 的构建、启动、数据恢复、安全限流、可观测性、自动化和运行态证据全部满足阶段卡要求。本验收单所在提交创建本地注解标签 `m8-acceptance`，不推送远端。
