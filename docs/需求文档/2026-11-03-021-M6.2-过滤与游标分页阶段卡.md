# 二级阶段 M6.2：让搜索能收窄和翻页

**一句话**：在 M6.1 全文搜索上增加集合、标签、时间过滤和稳定的游标分页。
**完成标志**：`GET /api/v1/search` 可组合过滤并返回 `items`、`nextCursor`、`hasMore`；相邻两页无重复、无遗漏，其他用户数据不可见。
**实施状态（2026-11-04）**：生产源码由用户手写，Codex 已补单元与 MySQL 8.4 集成测试；定向 12 项和全量 345 项测试通过（4 跳过）。
**预计时长**：2-4 小时　**依赖**：M6.1 已完成，V1-V14 已在 MySQL 8.4 验证

#### 1. 涉及技术栈（为什么是它）

| 技术/组件 | 用在哪 | 为什么选它 | 备选 & 不选的理由 |
|---|---|---|---|
| Spring MVC + Bean Validation | 绑定可重复查询参数并拒绝非法 `q`、`limit`、ID | 复用项目已有 Web 边界 | 在 Service 中静默修改非法参数会让客户端无法判断实际查询条件 |
| MyBatis 动态 SQL | 组合全文、集合、标签、时间和 keyset 条件 | 条件可独立开关，SQL 形状清楚 | QueryWrapper 不适合清晰表达 `MATCH` 和 `EXISTS` |
| MySQL 8.4 B-Tree 索引 | 按用户、集合和 `id DESC` 翻页 | 为预排序范围扫描提供访问路径 | 不增加索引时，用户过滤后仍可能要扫描、排序更多行 |
| Jackson + Base64URL | 编码游标 JSON | 不新增依赖，客户端不需要依赖内部字段名 | 纯数字游标无法绑定查询条件，条件变化后容易误翻页 |

#### 2. 原理讲解（不用它会怎样）

- **Keyset 分页**：游标携带上一页末项 `id`，下一页查询 `id < lastId`。不用它而用 `OFFSET`，前页新增或删除记录时可能重复或漏项，深页还要跳过大量行。
- **条件指纹**：游标把规范化查询条件做成摘要。换搜索词后误用旧游标会在同一页发现游标不匹配；不做校验则可能从另一组结果的任意位置继续，返回边界不可解释。
- **半开时间区间**：`from <= created_at < to` 让相邻区间首尾可拼接。全闭区间会让恰好落在边界毫秒的记录同时属于两个区间。
- **标签 `EXISTS`**：一个链接命中多个标签时只产生一个布尔结果。直接联表并在关联行上分页，会让同一链接占用多个结果位置。
- **用户范围条件**：`user_id = 当前会话用户` 是授权条件，不能交给游标或全文索引。漏掉它会把其他用户的收藏返回。

#### 3. 架构讲解（这一步在整体里占哪个位置）

- **分层位置**：`SearchController → LinkSearchService → LinkMapper → MySQL`。
- **数据流向**：读取查询参数 → Controller 做格式与范围校验 → Service 规范化条件、校验游标、读取当前用户 → Mapper 执行组合查询并多取一条探测下一页 → Service 生成页面和游标 → `ApiResponse<SearchPage>`。
- **改动边界**：新增搜索 DTO 与游标编解码器；修改搜索 Controller、Service、Mapper；新增 V15 普通索引迁移；同步接口文档和测试。不修改 V1-V14，不改 Worker、资产、任务或阅读视图。
- **为什么放这层**：Controller 只负责 HTTP 参数；Service 负责条件规范化、授权身份和分页语义；Mapper 只负责参数化 SQL。把安全条件放 Controller 会让其他 Service 调用绕过隔离。

#### 5. 重难语法讲解

- **`@RequestParam(value = "tagId", required = false) List<Long> tagIds`**：同名参数出现多次时绑定为列表。写错参数名 `tag` 会导致过滤被静默忽略；本卡固定使用 `tagId`。
- **MyBatis `<script>` + `<if>` + `<foreach>`**：注解中的动态 SQL 必须包在 `<script>` 内，`#{}` 仍是 JDBC 绑定参数。把 `${}` 用在搜索词或标签值上会形成 SQL 注入入口。
- **`LIMIT #{fetchLimit}`**：Service 查询 `limit + 1` 条，只返回前 `limit` 条。多取的一条只用于判断 `hasMore`，不能泄漏到响应。
- **`Base64.getUrlEncoder().withoutPadding()`**：游标放进 URL 查询参数时使用 URL 安全字符并去掉 `=`。它不是加密，也不是授权凭证。

##### `backend/src/main/java/com/webcollector/search/service/SearchCursorCodec.java`

- **作用**：编解码游标并为规范化搜索条件生成摘要。
- **完整代码**：

```java
package com.webcollector.search.service;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.webcollector.common.web.BusinessException;
import com.webcollector.common.web.ErrorCode;
import com.webcollector.search.dto.SearchCursor;
import org.springframework.stereotype.Component;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.time.Instant;
import java.util.Base64;
import java.util.List;
import java.util.stream.Collectors;

/**
 * 搜索游标编解码器。
 *
 * <p>[边界] Base64 只负责 URL 安全传输，不是加密；用户隔离始终由 SQL 的
 * user_id 条件保证。</p>
 */
@Component
public class SearchCursorCodec {
    private static final int CURRENT_VERSION = 1;

    private final ObjectMapper objectMapper;

    public SearchCursorCodec(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }

    public String encode(Long lastId, String fingerprint) {
        if (lastId == null || lastId <= 0
                || fingerprint == null || fingerprint.isBlank()) {
            throw new IllegalArgumentException("搜索游标参数不完整");
        }

        SearchCursor cursor = new SearchCursor(
                CURRENT_VERSION,
                lastId,
                fingerprint
        );

        try {
            byte[] json = objectMapper.writeValueAsBytes(cursor);
            return Base64.getUrlEncoder()
                    .withoutPadding()
                    .encodeToString(json);
        } catch (JsonProcessingException exception) {
            throw new IllegalStateException("无法编码搜索游标", exception);
        }
    }

    public SearchCursor decode(String encoded) {
        if (encoded == null || encoded.isBlank()) {
            throw invalidCursor();
        }

        try {
            byte[] json = Base64.getUrlDecoder().decode(encoded);
            SearchCursor cursor = objectMapper.readValue(json, SearchCursor.class);

            if (cursor == null
                    || cursor.version() != CURRENT_VERSION
                    || cursor.lastId() == null
                    || cursor.lastId() <= 0
                    || cursor.fingerprint() == null
                    || cursor.fingerprint().isBlank()) {
                throw invalidCursor();
            }

            return cursor;
        } catch (IllegalArgumentException | IOException exception) {
            throw invalidCursor();
        }
    }

    public String fingerprint(
            String query,
            Long collectionId,
            List<Long> tagIds,
            Instant from,
            Instant to
    ) {
        StringBuilder canonical = new StringBuilder();
        appendPart(canonical, query);
        appendPart(
                canonical,
                collectionId == null ? null : collectionId.toString()
        );
        appendPart(
                canonical,
                tagIds == null
                        ? null
                        : tagIds.stream()
                                .map(String::valueOf)
                                .collect(Collectors.joining(","))
        );
        appendPart(canonical, from == null ? null : from.toString());
        appendPart(canonical, to == null ? null : to.toString());

        try {
            byte[] digest = MessageDigest.getInstance("SHA-256")
                    .digest(canonical.toString().getBytes(StandardCharsets.UTF_8));
            return Base64.getUrlEncoder()
                    .withoutPadding()
                    .encodeToString(digest);
        } catch (NoSuchAlgorithmException exception) {
            throw new IllegalStateException("JRE 不提供 SHA-256", exception);
        }
    }

    private static void appendPart(StringBuilder target, String value) {
        if (value == null) {
            target.append("-1:");
        } else {
            target.append(value.length()).append(':').append(value);
        }
        target.append('|');
    }

    private static BusinessException invalidCursor() {
        return new BusinessException(
                ErrorCode.INVALID_REQUEST,
                "搜索游标无效"
        );
    }
}
```

```java
package com.webcollector.link.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.webcollector.link.entity.Link;
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;
import org.apache.ibatis.annotations.Update;

import java.time.LocalDateTime;
import java.util.List;

/**
 * [软件工程] BaseMapper 提供实体基础 CRUD；组合搜索使用显式参数化 SQL。
 *
 * [排错] 该接口没有实现类，由 MyBatis 动态代理生成；必须位于
 * @MapperScan("com.webcollector.**.mapper") 的扫描范围内。
 */
public interface LinkMapper extends BaseMapper<Link> {

    @Update("UPDATE link SET text_content = #{textContent} WHERE id = #{linkId}")
    int updateTextContentById(
            @Param("linkId") Long linkId,
            @Param("textContent") String textContent
    );

    @Select("""
            <script>
            SELECT l.id, l.user_id, l.collection_id, l.original_url,
                   l.normalized_url, l.url_hash, l.title, l.description,
                   l.created_at, l.updated_at
            FROM link l
            WHERE l.user_id = #{userId}
            <if test="query != null">
              AND MATCH(l.title, l.description, l.text_content)
                  AGAINST (#{query} IN NATURAL LANGUAGE MODE)
            </if>
            <if test="collectionId != null">
              AND l.collection_id = #{collectionId}
            </if>
            <if test="from != null">
              AND l.created_at &gt;= #{from}
            </if>
            <if test="to != null">
              AND l.created_at &lt; #{to}
            </if>
            <if test="tagIds != null and tagIds.size() > 0">
              AND EXISTS (
                  SELECT 1
                  FROM link_tag lt
                  WHERE lt.link_id = l.id
                    AND lt.tag_id IN
                    <foreach collection="tagIds"
                             item="tagId"
                             open="("
                             separator=","
                             close=")">
                      #{tagId}
                    </foreach>
              )
            </if>
            <if test="lastId != null">
              AND l.id &lt; #{lastId}
            </if>
            ORDER BY l.id DESC
            LIMIT #{fetchLimit}
            </script>
            """)
    List<Link> searchOwnedLinkPage(
            @Param("userId") Long userId,
            @Param("query") String query,
            @Param("collectionId") Long collectionId,
            @Param("tagIds") List<Long> tagIds,
            @Param("from") LocalDateTime from,
            @Param("to") LocalDateTime to,
            @Param("lastId") Long lastId,
            @Param("fetchLimit") int fetchLimit
    );
}
```

##### `backend/src/main/java/com/webcollector/search/service/LinkSearchService.java`

- **作用**：规范化条件、校验游标、隔离用户并组装分页结果。
- **完整代码**：

```java
package com.webcollector.search.service;

import com.webcollector.auth.session.SessionTokenService;
import com.webcollector.common.web.BusinessException;
import com.webcollector.common.web.ErrorCode;
import com.webcollector.link.dto.LinkSummary;
import com.webcollector.link.entity.Link;
import com.webcollector.link.mapper.LinkMapper;
import com.webcollector.search.dto.SearchCursor;
import com.webcollector.search.dto.SearchPage;
import com.webcollector.search.dto.SearchRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.time.ZoneOffset;
import java.util.List;

/**
 * 用户范围内的搜索与游标分页用例。
 */
@Service
public class LinkSearchService {
    private static final int MIN_LIMIT = 1;
    private static final int MAX_LIMIT = 100;

    private final LinkMapper linkMapper;
    private final SessionTokenService sessionTokenService;
    private final SearchCursorCodec cursorCodec;

    public LinkSearchService(
            LinkMapper linkMapper,
            SessionTokenService sessionTokenService,
            SearchCursorCodec cursorCodec
    ) {
        this.linkMapper = linkMapper;
        this.sessionTokenService = sessionTokenService;
        this.cursorCodec = cursorCodec;
    }

    @Transactional(readOnly = true)
    public SearchPage search(SearchRequest request) {
        if (request.limit() < MIN_LIMIT || request.limit() > MAX_LIMIT) {
            throw new BusinessException(
                    ErrorCode.INVALID_REQUEST,
                    "limit 必须在 1 到 100 之间"
            );
        }
        if (request.from() != null
                && request.to() != null
                && !request.from().isBefore(request.to())) {
            throw new BusinessException(
                    ErrorCode.INVALID_REQUEST,
                    "from 必须早于 to"
            );
        }

        String normalizedQuery = normalizeQuery(request.query());
        List<Long> normalizedTagIds = normalizeTagIds(request.tagIds());
        String fingerprint = cursorCodec.fingerprint(
                normalizedQuery,
                request.collectionId(),
                normalizedTagIds,
                request.from(),
                request.to()
        );
        SearchCursor cursor = decodeCursor(
                request.cursor(),
                fingerprint
        );
        Long userId = sessionTokenService.requireLoginId();

        List<Link> fetched = linkMapper.searchOwnedLinkPage(
                userId,
                normalizedQuery,
                request.collectionId(),
                normalizedTagIds,
                toUtcLocalDateTime(request.from()),
                toUtcLocalDateTime(request.to()),
                cursor == null ? null : cursor.lastId(),
                request.limit() + 1
        );

        boolean hasMore = fetched.size() > request.limit();
        List<Link> page = hasMore
                ? List.copyOf(fetched.subList(0, request.limit()))
                : fetched;
        List<LinkSummary> items = page.stream()
                .map(this::toSummary)
                .toList();
        String nextCursor = hasMore
                ? cursorCodec.encode(
                        page.get(page.size() - 1).getId(),
                        fingerprint
                )
                : null;

        return new SearchPage(items, nextCursor, hasMore);
    }

    private SearchCursor decodeCursor(String encoded, String fingerprint) {
        if (encoded == null) {
            return null;
        }

        SearchCursor cursor = cursorCodec.decode(encoded);
        if (!fingerprint.equals(cursor.fingerprint())) {
            throw new BusinessException(
                    ErrorCode.INVALID_REQUEST,
                    "搜索游标与查询条件不匹配"
            );
        }
        return cursor;
    }

    private static String normalizeQuery(String query) {
        if (query == null || query.isBlank()) {
            return null;
        }
        return query.trim();
    }

    private static List<Long> normalizeTagIds(List<Long> tagIds) {
        if (tagIds == null || tagIds.isEmpty()) {
            return List.of();
        }
        if (tagIds.stream().anyMatch(tagId -> tagId == null || tagId <= 0)) {
            throw new BusinessException(
                    ErrorCode.INVALID_REQUEST,
                    "tagId 必须为正数"
            );
        }
        return tagIds.stream()
                .distinct()
                .sorted()
                .toList();
    }

    private static LocalDateTime toUtcLocalDateTime(java.time.Instant instant) {
        return instant == null
                ? null
                : LocalDateTime.ofInstant(instant, ZoneOffset.UTC);
    }

    private LinkSummary toSummary(Link link) {
        return new LinkSummary(
                link.getId(),
                link.getCollectionId(),
                link.getOriginalUrl(),
                link.getTitle(),
                link.getDescription(),
                link.getCreatedAt().toInstant(ZoneOffset.UTC),
                link.getUpdatedAt().toInstant(ZoneOffset.UTC)
        );
    }
}
```

#### 7. 计算机四大件映射

- **映射到**：数据结构与算法。
- **具体机制**：B-Tree 复合索引按 `user_id` 缩小范围，再按 `id DESC` 扫描；keyset 条件 `id < lastId` 是范围查询。标签 `EXISTS` 把多行关联压成单个布尔判断。
- **在哪一行代码体现**：V15 的两条 `CREATE INDEX`、Mapper 的 `l.id < #{lastId}` 和 `EXISTS` 子查询。

#### 8. 坑（会怎么错，不是要注意什么）

- ❌ 用 `OFFSET` 做深页分页 → 前页数据变化时重复或漏项 → 使用 `id < lastId` keyset。
- ❌ 标签直接 `JOIN link_tag` 后分页 → 多标签链接出现多次 → 使用 `EXISTS`。
- ❌ 游标只存 `lastId` → 换搜索条件后仍继续翻页 → 绑定规范化条件指纹。
- ❌ 把 `from` 和 `to` 都写成 `>=`/`<=` → 相邻毫秒区间重叠 → `from` 包含、`to` 不包含。
- ❌ 忘记 `l.user_id = #{userId}` → 本次过滤仍可能泄露其他用户链接 → 用户 ID 只从会话获取。
