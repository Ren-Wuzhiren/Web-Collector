### 二级阶段 M4.3：让快照的正文能被检索

**一句话**：从浏览器生成的 HTML 中抽取正文，清理脚本、样式、导航和无关节点，输出稳定的可检索文本。
**完成标志**：本地动态页面经抽取后，正文保留，`script/style/nav/footer` 等噪音不出现在结果中，中文内容保持 UTF-8。
**实施状态（2026-11-03）**：正文抽取、正文落库、真实 Capture Worker、受控调度和三格式资产登记已接入；全量测试 327 项通过。
**预计时长**：一次实现会话　**依赖**：M4.1 已完成；可复用 M4.2 产生的 HTML 文件

#### 1. 涉及技术栈（为什么是它）

| 技术/组件 | 用在哪 | 为什么选它 | 备选 & 不选的理由 |
|---|---|---|---|
| Jsoup | 解析 HTML、删除噪音节点、输出清洗结果 | HTML DOM API 直观，适合当前先做确定性清洗 | 正则无法正确处理嵌套标签、实体和不完整 HTML |
| Java NIO | 读取输入 HTML、写入正文结果 | 明确使用 UTF-8，避免平台默认编码差异 | 暂不接 asset 表，文件元数据留给后续阶段 |
| JUnit 5 | 验证正文保留与噪音删除 | 可用本地固定 HTML 夹具稳定回归 | 不依赖真实网站，避免页面改版造成测试漂移 |

#### 2. 原理讲解（不用它会怎样）

- **DOM 清洗**：先解析成树，再按标签删除节点。不用它：正则很容易误删正文或漏掉嵌套脚本。
- **正文候选选择**：优先使用 `article/main`，没有时回退到 `body`。不用它：很多页面的导航和页脚会混进正文，搜索结果噪声很大。
- **文本标准化**：把连续空白压缩成单空格，保留段落换行。不用它：HTML 缩进会变成大量空行，正文不可读。

#### 3. 架构讲解（这一步在整体里占哪个位置）

- **分层位置**：`采集结果 → ReadableContentExtractor → Jsoup DOM → 清洗后的正文文件`。
- **数据流向**：

```text
读取 page.html
  → Jsoup.parse
  → 删除 script/style/noscript/nav/header/footer/aside/form
  → 选择 article/main/body
  → 提取 text 与清洗后的 HTML
  → 写 page.readable.txt / page.readable.html
```

**能讲（Codex 先示范，用户随后合上材料作答）**
- [ ] Q1：为什么正文抽取要先用 DOM 解析和节点删除，而不是用正则直接删 HTML？

  > **参考示范**：HTML 是嵌套树结构，DOM 解析能按元素边界删除脚本、导航和广告，不会因为正则匹配跨标签而误删正文；正则只适合做最后的文本空白整理。

- [ ] Q2：为什么 `article → main → body` 是回退顺序？

  > **参考示范**：`article` 通常最接近单篇正文，`main` 是页面主内容区域，`body` 是最后兜底；顺序越靠后，越可能混入导航、页脚等页面噪音。

#### 5. 重难语法讲解

- **Jsoup `Element.select`**：CSS 选择器一次选中多个噪音标签；用 `remove()` 从 DOM 树移除。
- **`Element.text()` 与 `html()`**：`text()` 生成可搜索纯文本，`html()` 保留清洗后的结构；两者用途不同，不能只保留一个。
- **空白规范化**：用正则压缩每行空白，再过滤连续空行；不要全局删除换行，否则段落会粘在一起。

##### `backend/src/main/java/com/webcollector/capture/content/ReadableContentExtractor.java`

```java
package com.webcollector.capture.content;

import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.regex.Pattern;

/** 从 HTML 中抽取正文并删除常见页面噪音。 */
public class ReadableContentExtractor {

    private static final List<String> NOISE_SELECTORS = List.of(
            "script",
            "style",
            "noscript",
            "nav",
            "header",
            "footer",
            "aside",
            "form",
            "広告",
            ".advertisement",
            ".ads",
            ".cookie-banner"
    );

    private static final Pattern HORIZONTAL_WHITESPACE =
            Pattern.compile("[\\t\\x0B\\f\\r ]+");

    private static final Pattern MULTIPLE_BLANK_LINES =
            Pattern.compile("\\n{3,}");

    /** 从 HTML 字符串抽取正文。 */
    public ReadableContent extract(String sourceHtml) {
        if (sourceHtml == null || sourceHtml.isBlank()) {
            throw new IllegalArgumentException("sourceHtml 不能为空");
        }

        Document document = Jsoup.parse(sourceHtml);
        removeNoise(document);

        Element contentRoot = chooseContentRoot(document);
        String text = normalizeText(contentRoot.text());
        String html = contentRoot.html().trim();

        return new ReadableContent(text, html);
    }

    /** 从 HTML 文件读取并抽取正文。 */
    public ReadableContent extract(Path htmlPath) {
        if (htmlPath == null) {
            throw new IllegalArgumentException("htmlPath 不能为空");
        }

        try {
            return extract(Files.readString(htmlPath, StandardCharsets.UTF_8));
        } catch (IOException exception) {
            throw new IllegalStateException(
                    "读取 HTML 文件失败: " + htmlPath,
                    exception
            );
        }
    }

    /** 抽取并把纯文本和清洗 HTML 写入目标目录。 */
    public ReadableContent extractToFiles(
            Path htmlPath,
            Path outputDirectory
    ) {
        ReadableContent content = extract(htmlPath);

        try {
            Files.createDirectories(outputDirectory);
            Files.writeString(
                    outputDirectory.resolve("page.readable.txt"),
                    content.text(),
                    StandardCharsets.UTF_8
            );
            Files.writeString(
                    outputDirectory.resolve("page.readable.html"),
                    content.html(),
                    StandardCharsets.UTF_8
            );
            return content;
        } catch (IOException exception) {
            throw new IllegalStateException(
                    "写入正文文件失败: " + outputDirectory,
                    exception
            );
        }
    }

    private void removeNoise(Document document) {
        for (String selector : NOISE_SELECTORS) {
            document.select(selector).remove();
        }
    }

    private Element chooseContentRoot(Document document) {
        Element article = document.selectFirst("article");
        if (article != null) {
            return article;
        }

        Element main = document.selectFirst("main");
        if (main != null) {
            return main;
        }

        return document.body();
    }

    private String normalizeText(String text) {
        String normalized = HORIZONTAL_WHITESPACE
                .matcher(text)
                .replaceAll(" ")
                .trim();

        return MULTIPLE_BLANK_LINES
                .matcher(normalized)
                .replaceAll("\\n\\n")
                .trim();
    }
}
```

##### `backend/src/test/java/com/webcollector/capture/content/ReadableContentExtractorTest.java`

```java
package com.webcollector.capture.content;

import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class ReadableContentExtractorTest {

    private final ReadableContentExtractor extractor =
            new ReadableContentExtractor();

    // [测试意图] 验证 article 正文保留，同时删除导航、脚本、样式和广告。
    @Test
    void shouldExtractArticleAndRemoveNoise() {
        String html = """
                <html>
                <head><style>.hidden { display: none; }</style></head>
                <body>
                    <nav>导航菜单</nav>
                    <article>
                        <h1>网页标题</h1>
                        <p>这是中文正文。</p>
                        <script>alert('noise')</script>
                        <div class="ads">广告内容</div>
                    </article>
                    <footer>页脚信息</footer>
                </body>
                </html>
                """;

        ReadableContent content = extractor.extract(html);

        assertThat(content.text())
                .contains("网页标题")
                .contains("这是中文正文")
                .doesNotContain("导航菜单")
                .doesNotContain("alert")
                .doesNotContain("广告内容")
                .doesNotContain("页脚信息");
        assertThat(content.html()).contains("这是中文正文");
    }

    // [测试意图] 验证没有 article 时回退到 main，再没有 main 时使用 body。
    @Test
    void shouldFallbackFromMainToBody() {
        ReadableContent mainContent = extractor.extract("""
                <body><main><p>主要正文</p></main><div>其他内容</div></body>
                """);
        ReadableContent bodyContent = extractor.extract("""
                <body><p>Body 正文</p><div>补充内容</div></body>
                """);

        assertThat(mainContent.text()).contains("主要正文");
        assertThat(mainContent.text()).doesNotContain("其他内容");
        assertThat(bodyContent.text())
                .contains("Body 正文")
                .contains("补充内容");
    }

    // [测试意图] 验证中文 UTF-8 文件读取、抽取和写回不会乱码。
    @Test
    void shouldReadAndWriteUtf8Files(@TempDir Path tempDir)
            throws IOException {
        Path input = tempDir.resolve("page.html");
        Path output = tempDir.resolve("readable");
        Files.writeString(
                input,
                "<article><p>你好，正文检索。</p></article>",
                StandardCharsets.UTF_8
        );

        ReadableContent content = extractor.extractToFiles(input, output);

        assertThat(content.text()).isEqualTo("你好，正文检索。");
        assertThat(Files.readString(
                output.resolve("page.readable.txt"),
                StandardCharsets.UTF_8
        )).isEqualTo("你好，正文检索。");
        assertThat(Files.readString(
                output.resolve("page.readable.html"),
                StandardCharsets.UTF_8
        )).contains("你好，正文检索");
    }

    // [测试意图] 验证空输入和不存在文件会被明确拒绝。
    @Test
    void shouldRejectBlankHtmlAndMissingFile(@TempDir Path tempDir) {
        assertThatThrownBy(() -> extractor.extract("  "))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("sourceHtml");

        assertThatThrownBy(() -> extractor.extract(
                tempDir.resolve("missing.html")
        ))
                .isInstanceOf(IllegalStateException.class)
                .hasMessageContaining("读取 HTML 文件失败");
    }
}
```
