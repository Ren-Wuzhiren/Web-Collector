## 2. 原理讲解（不用它会怎样）

- **【主题属性】**：`html[data-theme]` 和 `.dark` 同时表达当前主题，Element Plus 读取 `.dark`，项目 token 读取 `data-theme`、**不用会怎样**：项目变量已切换，但下拉框、日期选择器和确认框仍保持亮色。
- **【语义 token】**：组件只消费 `--ground`、`--surface`、`--text` 等角色，不读取具体色值、**不用会怎样**：切到浅色时出现局部仍然是暗色的“拼接界面”。
- **【稳定哈希图形】**：档案封面从链接 ID、域名和标题计算，**不用会怎样**：刷新页面后同一收藏换图，界面产生无意义跳变。
- **【本地偏好】**：主题和网格/列表选择写入 `localStorage`，**不用会怎样**：每次刷新都回到默认视图，无法形成稳定工作习惯。

## 3. 架构讲解（这一步在整体里占哪个位置）

- **分层位置**：浏览器 localStorage → Vue 主题工具/收藏页状态 → CSS token → 页面和 Element Plus。
- **数据流向**：主题按钮 → `theme.js` 更新 `documentElement` → CSS variables 与 Element Plus 同步换色 → localStorage 保存；收藏视图按钮 → `LinksView` 状态 → 网格/列表渲染 → localStorage 保存。
- **改动边界**：只改 `frontend/`、设计文档、协作规则和验收文档；不改后端 Controller、Service、Mapper、API、数据库和路由路径。
- **为什么放这层**：主题属于纯浏览器呈现偏好，不应进入用户业务表或增加后端接口。

## 5. 重难语法讲解

- **【CSS 主题选择器】**：`:root[data-theme="dark"], :root.dark { ... }` → 同时兼容自定义组件和 Element Plus；**常见错法**：只切 class，导致 `tokens.css` 的 `data-theme` 规则不生效。
- **【焦点状态】**：`:focus-visible` 使用 2px `--accent` 和 3px offset；**常见错法**：`outline: none` 后没有替代，键盘用户看不到位置。
- **【本地存储降级】**：读取和写入都包在 `try/catch`；**常见错法**：隐私模式抛出异常后整个应用启动失败。
- **【无障碍开关】**：主题按钮用 `aria-pressed="isDark"`，名称随目标动作变化；**常见错法**：只放太阳/月亮图标且没有标签。

## 8. 坑（会怎么错，不是要注意什么）

- ❌ 只给页面背景加黑色 → Element Plus 弹层仍是亮色 → 同时设置 `.dark`、`data-theme` 并覆盖组件变量。
- ❌ 在组件里直接写 `#141413` → 浅色主题出现暗块 → 使用语义 token。
- ❌ 档案封面使用 `Math.random()` → 刷新后换图 → 使用 ID/域名/标题稳定哈希。
- ❌ 为未知数量强行补满三列 → 产生假数据和空洞 → 按真实记录数结束网格。
- ❌ 移动端继续保留固定侧栏 → 内容宽度不足 → 56px 顶栏和全屏导航面板。
