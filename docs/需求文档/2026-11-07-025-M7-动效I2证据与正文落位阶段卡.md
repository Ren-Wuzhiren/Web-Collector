## 完成标志

1. 任务从 PENDING/RUNNING 进入终态时，正文与证据行做一次 opacity 淡入。
2. 首次打开已完成的收藏不播放任何动效。
3. 缺失的证据项保持静态，标签改为“不可用”。
4. reduced-motion 下没有动画，终态直接可见，布局不变。
5. 正文区域不使用 `transform`、`scale` 或视差。

## 数据流与判断

- `fetchJob` 在覆盖 `job.value` 之前记录上一次状态。
- 只有上一次是 `PENDING` 或 `RUNNING`，且本次是终态时，才把 `jobJustSettled` 置为 `true`。
- 这个判断放在 `fetchJob` 里，因为它是唯一能看到状态迁移的地方。`loadDetail` 每次切换收藏都会把它重置为 `false`。
- 模板里 `.evidence-list` 和 `.readable-text` 绑定 `is-settling` 类。元素挂载时带上这个类，CSS 动画才会播放。

## 动效规格

| 项目 | 内容 |
|---|---|
| 触发 | 任务进入终态，且此前为 PENDING/RUNNING |
| 时长 / 缓动 | `--motion-fast`（140ms）/ `--ease-out` |
| 起止状态 | opacity 0 → 1，无位移 |
| 错峰 | 证据行每行 `--row-index * 60ms`；正文无错峰 |
| 不播放 | 缺失行（`.is-missing`）；首次加载已完成的收藏 |
| reduced-motion | 动画规则放在 `prefers-reduced-motion: no-preference` 内，直接显示终态 |
| 传达的信息 | 副本与正文已经生成 |
