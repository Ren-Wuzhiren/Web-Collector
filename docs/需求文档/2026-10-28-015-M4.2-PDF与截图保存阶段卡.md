### 二级阶段 M4.2：让快照更像原网页

**一句话**：一次浏览器导航同时保存渲染后 HTML、PDF 和全页截图。
**完成标志**：本地动态页面经同一 Page 导航后，在输出目录查到非空 `page.html`、A4 `page.pdf` 和 `screenshot.png`。
**实施状态（2026-10-28）**：阶段卡已拟定，待用户确认后实现。
**预计时长**：一次实现会话　**依赖**：M4.1 已完成

---

#### 1. 涉及技术栈（为什么是它）

| 技术/组件 | 用在哪 | 为什么选它 | 备选 & 不选的理由 |
|---|---|---|---|
| Playwright Java 1.49.0 | 从同一 Page 导出 PDF 和全页截图 | 复用 M4.1 Chromium 导航和已经渲染的 DOM | 单独 HTTP 转 PDF 无法保留浏览器渲染结果 |
| Chromium | 输出 PDF 与 PNG | Playwright 的 `page.pdf` 由 Chromium 提供；截图直接读取同一页面 | 多开浏览器会重复导航且可能捕获不同页面状态 |
| `java.nio.file.Files` | 建目录、检查输出和失败清理 | 标准 API 足够管理三种本地文件 | 暂不新增 asset 表，文件元数据持久化留给 M5.1 |

#### 2. 原理讲解（不用它会怎样）

- **同一页面多格式导出**：HTML、PDF、截图都从同一 Page 生成。不用它：分别启动浏览器可能遇到页面变化、登录态差异或资源加载差异。
- **PDF 与截图介质**：PDF 使用打印布局并开启背景图形；截图使用屏幕渲染并截取完整可滚动页面。不用它：PDF 可能丢背景，截图可能只剩首屏。
- **本阶段全有或全无**：每次调用只允许写入自己的三个固定文件；任一格式失败就删除本次生成的文件并报错。不用它：目录会残留一份看似成功但格式不完整的快照；部分成功保留策略留给 M4.5。

#### 3. 架构讲解（这一步在整体里占哪个位置）

- **分层位置**：`Worker/采集服务 → PlaywrightBrowserHtmlCapture → Browser/Page → 文件系统`。
- **数据流向**：

```text
captureSnapshot(url, outputDirectory)
  → 校验 HTTP/HTTPS 与参数
  → 创建输出目录并确保三个目标文件不存在
  → 启动一次 Playwright/Chromium/Context/Page
  → navigate 一次
  → page.content() 写 page.html
  → 全页 PNG 写 screenshot.png
  → A4 PDF 写 page.pdf
  → 返回三个绝对路径
  → 任一步失败：删除本次生成的文件，抛出采集异常
```

- **改动边界**：保留 M4.1 的 `capture(url, outputPath)`；新增组合快照结果类型和 `captureSnapshot(url, outputDirectory)`。不接 `CaptureJobService`、不新增 asset 表、HTTP API、SSRF、正文抽取或任务状态策略。
- **为什么放这层**：浏览器页面导出属于采集基础设施；不放进任务 Service，避免任务状态和浏览器 API 耦合。

#### 4. 步骤（每步都能看到结果）

| # | 做什么 | 完成后能观察到什么 |
|---|---|---|
| 1 | 定义 `BrowserCaptureArtifacts` 路径结果 | 调用方能分别取得 HTML、PDF、PNG 路径 |
| 2 | 新增组合快照入口 | 一次调用只导航一次，生成三个格式 |
| 3 | 实现输出目录、冲突检查和失败清理 | 不覆盖旧文件，异常后不留下本次半成品 |
| 4 | 扩展本地动态页面测试 | HTML 有渲染结果，PDF 有 `%PDF-` 签名，PNG 有正确文件签名 |
| 5 | 验证生命周期和回归 | 浏览器关闭；M4.1 HTML 单格式接口继续工作 |
| 6 | 同步任务清单与测试文档 | M4.2 验收事实与实现一致 |

#### 5. 重难语法讲解

- **`Page.pdf(PdfOptions)`**：使用 `setPath`、`setFormat("A4")`、`setPrintBackground(true)`；PDF 导出使用打印介质。
- **`Page.screenshot(ScreenshotOptions)`**：使用 `setPath` 和 `setFullPage(true)`；路径扩展名使用 `.png`，由 Playwright 输出 PNG。
- **失败清理**：先确认目标文件调用前不存在，再跟踪本次已创建的路径；失败时只删除这些路径，不对输出目录递归删除。

##### `backend/src/main/java/com/webcollector/capture/browser/PlaywrightBrowserHtmlCapture.java`

```java
package com.webcollector.capture.browser;

import com.microsoft.playwright.Browser;
import com.microsoft.playwright.BrowserContext;
import com.microsoft.playwright.BrowserType;
import com.microsoft.playwright.Page;
import com.microsoft.playwright.Playwright;
import com.microsoft.playwright.options.ScreenshotType;
import org.springframework.stereotype.Service;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

/** 使用同一 Chromium Page 捕获 HTML、PDF 和全页截图。 */
@Service
public class PlaywrightBrowserHtmlCapture implements BrowserHtmlCapture {

    private static final int NAVIGATION_TIMEOUT_MILLIS = 30_000;
    private static final int VIEWPORT_WIDTH = 1280;
    private static final int VIEWPORT_HEIGHT = 720;

    @Override
    public Path capture(String url, Path outputPath) {
        validateUrl(url);
        if (outputPath == null) {
            throw new IllegalArgumentException("outputPath 不能为空");
        }

        Path target = outputPath.toAbsolutePath().normalize();
        createParentDirectories(target);

        return withPage(url, page -> {
            Files.writeString(
                    target,
                    page.content(),
                    StandardCharsets.UTF_8
            );
            return target;
        });
    }

    @Override
    public BrowserCaptureArtifacts captureSnapshot(
            String url,
            Path outputDirectory
    ) {
        validateUrl(url);
        if (outputDirectory == null) {
            throw new IllegalArgumentException(
                    "outputDirectory 不能为空"
            );
        }

        Path directory = outputDirectory.toAbsolutePath().normalize();
        Path htmlPath = directory.resolve("page.html");
        Path pdfPath = directory.resolve("page.pdf");
        Path screenshotPath = directory.resolve("screenshot.png");
        List<Path> outputs = List.of(htmlPath, pdfPath, screenshotPath);

        for (Path output : outputs) {
            if (Files.exists(output)) {
                throw new IllegalStateException(
                        "快照文件已存在，拒绝覆盖: " + output
                );
            }
        }

        createDirectories(directory);

        try {
            return withPage(url, page -> {
                Files.writeString(
                        htmlPath,
                        page.content(),
                        StandardCharsets.UTF_8
                );

                // 先截屏，再调用 PDF 导出，避免打印介质影响截图样式。
                page.screenshot(
                        new Page.ScreenshotOptions()
                                .setPath(screenshotPath)
                                .setFullPage(true)
                                .setType(ScreenshotType.PNG)
                );

                page.pdf(
                        new Page.PdfOptions()
                                .setPath(pdfPath)
                                .setFormat("A4")
                                .setPrintBackground(true)
                );

                return new BrowserCaptureArtifacts(
                        htmlPath,
                        pdfPath,
                        screenshotPath
                );
            });
        } catch (RuntimeException exception) {
            deletePartialOutputs(outputs, exception);
            throw exception;
        }
    }

    private <T> T withPage(String url, PageAction<T> action) {
        try (
                Playwright playwright = Playwright.create();
                Browser browser = playwright.chromium().launch(
                        new BrowserType.LaunchOptions().setHeadless(true)
                );
                BrowserContext context = browser.newContext(
                        new Browser.NewContextOptions().setViewportSize(
                                VIEWPORT_WIDTH,
                                VIEWPORT_HEIGHT
                        )
                );
                Page page = context.newPage()
        ) {
            page.setDefaultNavigationTimeout(NAVIGATION_TIMEOUT_MILLIS);
            page.navigate(url);
            return action.apply(page);
        } catch (IOException exception) {
            throw new IllegalStateException(
                    "快照文件操作失败",
                    exception
            );
        } catch (RuntimeException exception) {
            throw new IllegalStateException(
                    "网页捕获失败: " + url,
                    exception
            );
        }
    }

    private void validateUrl(String url) {
        if (url == null || url.isBlank()) {
            throw new IllegalArgumentException("url 不能为空");
        }

        String normalized = url.trim().toLowerCase(java.util.Locale.ROOT);
        if (!normalized.startsWith("http://")
                && !normalized.startsWith("https://")) {
            throw new IllegalArgumentException(
                    "仅允许 HTTP/HTTPS URL"
            );
        }
    }

    private void createParentDirectories(Path outputPath) {
        Path parent = outputPath.getParent();
        if (parent != null) {
            createDirectories(parent);
        }
    }

    private void createDirectories(Path directory) {
        try {
            Files.createDirectories(directory);
        } catch (IOException exception) {
            throw new IllegalStateException(
                    "创建输出目录失败: " + directory,
                    exception
            );
        }
    }

    private void deletePartialOutputs(
            List<Path> outputs,
            RuntimeException originalFailure
    ) {
        List<IOException> cleanupFailures = new ArrayList<>();

        for (Path output : outputs) {
            try {
                Files.deleteIfExists(output);
            } catch (IOException cleanupFailure) {
                cleanupFailures.add(cleanupFailure);
            }
        }

        cleanupFailures.forEach(originalFailure::addSuppressed);
    }

    @FunctionalInterface
    private interface PageAction<T> {
        T apply(Page page) throws IOException;
    }
}
```

##### `backend/src/test/java/com/webcollector/capture/browser/PlaywrightBrowserHtmlCaptureTest.java`

```java
package com.webcollector.capture.browser;

import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;
import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;

import java.io.IOException;
import java.io.OutputStream;
import java.io.UncheckedIOException;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Arrays;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicInteger;

import javax.imageio.ImageIO;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class PlaywrightBrowserHtmlCaptureTest {

    private static final byte[] PNG_SIGNATURE = new byte[]{
            (byte) 0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A
    };

    private HttpServer httpServer;
    private ExecutorService httpExecutor;
    private AtomicInteger navigationCount;
    private PlaywrightBrowserHtmlCapture capture;

    @BeforeEach
    void setUp() throws IOException {
        capture = new PlaywrightBrowserHtmlCapture();
        navigationCount = new AtomicInteger();
        httpServer = HttpServer.create(
                new InetSocketAddress("localhost", 0),
                0
        );
        httpServer.createContext("/dynamic", this::handleDynamicPage);
        httpExecutor = Executors.newFixedThreadPool(2);
        httpServer.setExecutor(httpExecutor);
        httpServer.start();
    }

    @AfterEach
    void tearDown() {
        if (httpServer != null) {
            httpServer.stop(0);
        }
        if (httpExecutor != null) {
            httpExecutor.shutdownNow();
        }
    }

    // [测试意图] 验证 M4.1 接口仍能保存浏览器执行 JavaScript 后的 DOM。
    @Test
    void shouldSaveRenderedHtmlToFile(@TempDir Path tempDir) throws IOException {
        Path outputPath = tempDir.resolve("archive.html");

        Path savedPath = capture.capture(localUrl("/dynamic"), outputPath);

        assertThat(savedPath).isEqualTo(outputPath.toAbsolutePath().normalize());
        assertThat(Files.exists(savedPath)).isTrue();
        assertThat(Files.readString(savedPath, StandardCharsets.UTF_8))
                .contains("动态内容已渲染")
                .contains("data-rendered=\"true\"");
    }

    // [测试意图] 验证 M4.1 接口会创建缺失的父目录并写入非空文件。
    @Test
    void shouldCreateParentDirectoriesAndWriteNonEmptyFile(
            @TempDir Path tempDir
    ) throws IOException {
        Path outputPath = tempDir.resolve("nested").resolve("page.html");

        Path savedPath = capture.capture(localUrl("/dynamic"), outputPath);

        assertThat(Files.exists(savedPath)).isTrue();
        assertThat(Files.size(savedPath)).isPositive();
    }

    // [测试意图] 验证一次导航由同一 Page 产出 HTML、A4 PDF 和完整长页面截图。
    @Test
    void shouldCaptureHtmlPdfAndFullPageScreenshotFromOneNavigation(
            @TempDir Path tempDir
    ) throws IOException {
        Path outputDirectory = tempDir.resolve("snapshot");

        BrowserCaptureArtifacts artifacts = capture.captureSnapshot(
                localUrl("/dynamic"),
                outputDirectory
        );

        assertThat(artifacts.htmlPath()).isEqualTo(
                outputDirectory.resolve("page.html").toAbsolutePath().normalize()
        );
        assertThat(artifacts.pdfPath()).isEqualTo(
                outputDirectory.resolve("page.pdf").toAbsolutePath().normalize()
        );
        assertThat(artifacts.screenshotPath()).isEqualTo(
                outputDirectory.resolve("screenshot.png")
                        .toAbsolutePath()
                        .normalize()
        );

        assertThat(Files.size(artifacts.htmlPath())).isPositive();
        assertThat(Files.size(artifacts.pdfPath())).isPositive();
        assertThat(Files.size(artifacts.screenshotPath())).isPositive();
        assertThat(Files.readString(
                artifacts.htmlPath(),
                StandardCharsets.UTF_8
        )).contains("动态内容已渲染");

        byte[] pdfBytes = Files.readAllBytes(artifacts.pdfPath());
        assertThat(new String(
                pdfBytes,
                0,
                Math.min(pdfBytes.length, 5),
                StandardCharsets.US_ASCII
        )).isEqualTo("%PDF-");

        byte[] screenshotBytes = Files.readAllBytes(
                artifacts.screenshotPath()
        );
        assertThat(Arrays.copyOf(screenshotBytes, PNG_SIGNATURE.length))
                .containsExactly(PNG_SIGNATURE);

        var screenshot = ImageIO.read(artifacts.screenshotPath().toFile());
        assertThat(screenshot).isNotNull();
        assertThat(screenshot.getHeight()).isGreaterThan(720);
        assertThat(navigationCount.get()).isEqualTo(1);
    }

    // [测试意图] 验证目标文件冲突时拒绝覆盖已有快照文件。
    @Test
    void shouldRefuseToOverwriteExistingSnapshotFile(
            @TempDir Path tempDir
    ) throws IOException {
        Path outputDirectory = tempDir.resolve("existing");
        Files.createDirectories(outputDirectory);
        Path existingHtml = outputDirectory.resolve("page.html");
        Files.writeString(
                existingHtml,
                "previous snapshot",
                StandardCharsets.UTF_8
        );

        assertThatThrownBy(() -> capture.captureSnapshot(
                localUrl("/dynamic"),
                outputDirectory
        ))
                .isInstanceOf(IllegalStateException.class)
                .hasMessageContaining("拒绝覆盖");

        assertThat(Files.readString(existingHtml, StandardCharsets.UTF_8))
                .isEqualTo("previous snapshot");
        assertThat(navigationCount.get()).isZero();
    }

    // [测试意图] 验证不支持的 URL scheme 在启动浏览器前被拒绝。
    @Test
    void shouldRejectNonHttpUrl(@TempDir Path tempDir) {
        assertThatThrownBy(() -> capture.capture(
                "ftp://example.com/page",
                tempDir.resolve("invalid.html")
        ))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("HTTP/HTTPS");
    }

    // [测试意图] 验证空 URL 和空输出路径被拒绝。
    @Test
    void shouldRejectBlankArguments(@TempDir Path tempDir) {
        assertThatThrownBy(() -> capture.capture(
                "",
                tempDir.resolve("invalid.html")
        ))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("url");

        assertThatThrownBy(() -> capture.captureSnapshot(
                localUrl("/dynamic"),
                null
        ))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("outputDirectory");
    }

    private void handleDynamicPage(HttpExchange exchange) {
        navigationCount.incrementAndGet();
        String body = """
                <!doctype html>
                <html>
                <head>
                    <meta charset="UTF-8">
                    <title>M4.2 Test Page</title>
                    <style>body { min-height: 1800px; }</style>
                </head>
                <body>
                    <div id="app">等待脚本执行</div>
                    <script>
                        const app = document.getElementById('app');
                        app.textContent = '动态内容已渲染';
                        app.dataset.rendered = 'true';
                    </script>
                </body>
                </html>
                """;
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);

        try {
            exchange.getResponseHeaders().set(
                    "Content-Type",
                    "text/html; charset=UTF-8"
            );
            exchange.sendResponseHeaders(200, bytes.length);
            try (OutputStream output = exchange.getResponseBody()) {
                output.write(bytes);
            }
        } catch (IOException exception) {
            throw new UncheckedIOException(exception);
        } finally {
            exchange.close();
        }
    }

    private String localUrl(String path) {
        return "http://localhost:"
                + httpServer.getAddress().getPort()
                + path;
    }
}
```

#### 7. 计算机四大件映射

- **映射到**：操作系统 + 计算机网络。
- **具体机制**：同一浏览器进程的资源生命周期、文件创建/清理；一次 HTTP 导航结果被多种本地格式消费。
- **在哪一行代码体现**：try-with-resources 管理 Browser/Context/Page，`page.navigate` 只调用一次，三个导出方法共用该 Page。

#### 8. 坑（会怎么错，不是要注意什么）

- ❌ 为 HTML/PDF/截图各启动一次浏览器 → 三份内容可能来自不同页面状态且资源开销翻倍 → 一个 Page 导出三种格式。
- ❌ 先 PDF 后截图但未留意介质切换 → 截图可能带打印样式 → 先 HTML、再全页截图、最后 PDF。
- ❌ 直接覆盖已有文件 → 失败时可能破坏旧快照 → 目标存在就拒绝，本次只清理自己新建的文件。
- ❌ 用 `Files.delete(outputDirectory)` 或递归删除 → 误删目录中其他数据 → 只删除本次记录的三个精确文件路径。
- ❌ 把任一格式失败直接映射为整个 Job 失败或保留部分产物 → 混入 M4.5 的失败策略 → 本步只返回成功三件套或抛错并清理。

- [ ] Q1：为什么三种输出应复用同一个 Page，而不是分别导航三次？

  > **参考示范**：复用同一个 Page 可确保 HTML、PDF 和截图来自同一页面状态与同一次资源加载；分别导航会产生页面变化和资源状态差异，也多消耗浏览器资源。

- [ ] Q2：为什么 M4.2 暂时采用全有或全无，而不保留部分格式成功结果？

  > **参考示范**：当前阶段只验收完整三格式快照，还没有 asset 元数据和部分成功状态契约；失败时清理本次产物可避免目录里出现被误认为完整的残缺快照，部分成功策略留到 M4.5 统一设计。
