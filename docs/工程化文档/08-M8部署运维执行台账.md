### 启动时序修复

首次启动时 backend 因 `Connection refused` 退出。根因是 MySQL 初始化阶段临时实例只监听 socket，而 Compose healthcheck 使用 `localhost` 时会被该临时实例提前判定为 healthy。健康检查改用 `127.0.0.1` 强制 TCP 后，重新创建 MySQL 容器并从头启动整套栈，backend 无需人工重启即可完成 V1–V17 迁移并启动。
