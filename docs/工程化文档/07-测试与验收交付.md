### 真实 URL 验收

`scripts/acceptance/m9-real-urls.json` 固定 30 项，覆盖：

- 普通新闻或博客页面。
- 中文技术文章。
- GitHub 项目页。
- 带大量图片的页面。
- 重定向和短链接。
- 超时、403、404 和拒绝访问页面。
- 直接 PDF 和直接图片 URL。
- 重复保存由脚本自动化测试覆盖；重新采集不在 M9.1 固定数据集中，留待后续端到端验收。

测试入口：

```powershell
node --test .\scripts\tests\accept-real-urls.test.mjs
```

真实运行入口：

```powershell
pwsh -NoProfile -NonInteractive -File .\scripts\accept-real-urls.ps1 `
  -BaseUrl http://127.0.0.1:18080 `
  -DatasetFile .\scripts\acceptance\m9-real-urls.json `
  -OutputFile .\data\acceptance\m9\results.json `
  -JobTimeoutSeconds 300 `
  -PollIntervalSeconds 3
```

脚本测试覆盖数据集契约、26/4 配比、聚合门槛、无资产、资产不可读、轮询超时、409 和 429 重试。真实运行必须等 `summary.passed=true` 且退出码为 0 才算通过。

## 验收指标

- 首次保存成功率 >= 90%。
- 中位完成时间 <= 30 秒。
- 任务失败后错误原因可见。
- Worker 重启后待处理任务不丢失。
- 同一 URL 不会在同一用户下生成多个链接。
- 不允许保存 localhost、私网和云元数据地址。
- 中文和英文标题、正文均能检索。
