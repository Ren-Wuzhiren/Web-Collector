# 项目阶段说明

> **进度快照：2026-11-07**。本文件用于快速了解项目从工程基线到 MVP 交付的阶段安排和当前位置；详细里程碑状态以[阶段任务清单](需求文档/2026-10-07-007-架构设计各阶段任务清单.md)为准。

## 项目目标

本项目要实现一个个人自托管的网页收藏与内容保存系统：用户提交网页 URL 后，系统保存链接元数据并异步采集网页快照，之后可以整理、检索和回看。

## 阶段与里程碑

阶段（`M0`–`M9`）表示一组相关能力的较大建设方向；里程碑（例如 `M2.6`）表示阶段内可独立实现和验收的增量。

项目保留现有 M 编号，详细范围、验收项和实施记录见阶段任务清单及各里程碑阶段卡。

```text
M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7（当前）→ M8 → M9
```
