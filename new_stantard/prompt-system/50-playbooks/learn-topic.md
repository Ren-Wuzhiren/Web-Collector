# 剧本：学一个主题

> 适用：从零学一个主题，或把半懂的内容学透。
> 不适用：只查一个术语；直接用概念讲解卡。
> 原则：**诊断 → 讲解 → 练习 → 项目/应用 → 复习；不跳过后面的输出环节。**

## 阶段流程

| 阶段 | 使用场景卡 | 产物 | 通过条件 |
|---|---|---|---|
| 1 诊断 | `30-learning/01-diagnosis.md` | 知识地图、起点 | 明确已会/半懂/空白/误区 |
| 2 规划 | `30-learning/07-learning-plan.md` | 8 周计划或本次路线 | 目标、时间、交付物明确 |
| 3 讲解 | `30-learning/02-concept-tutor.md` | 直觉、定义、例子、反例 | 能回答检查题 |
| 4 练习 | `30-learning/03-socratic-practice.md` | 变式题、薄弱点 | 能解释为什么、能迁移 |
| 5 应用 | `30-learning/05-project-learning.md` 或 `04-code-reading.md` | 小项目/链路图 | 有可演示成果 |
| 6 复习 | `30-learning/06-spaced-review.md` | 复习日程、错题本 | 间隔节点已排 |

## 启动提示词

```text
我想学 {{主题}}，请按“诊断 → 规划 → 讲解 → 练习 → 应用 → 复习”带我，不要一上来倾倒知识。

【学习者卡】
{{LEARNER_CARD}}

【目标】
{{为什么学：课程/项目/面试/兴趣；学到什么程度}}

【时间】
{{每周小时数、单次时长}}

先做诊断：一次只问我一个问题，8–12 题，根据回答调整。
诊断结束前不要系统讲课。
```

## 第 1 阶段：诊断

检查：

- [ ] 覆盖概念、原理、应用三层。
- [ ] 一次一问，有我的原话作证据。
- [ ] 区分“不会”和“错误理解”。

## 第 2 阶段：规划

检查：

- [ ] 只规划 8 周或本次范围。
- [ ] 每周有交付物，不只是看书。
- [ ] 时间匹配真实投入。

## 第 3 阶段：讲解

每次只讲一个概念，检查：

- [ ] 有直觉、定义、例子、反例。
- [ ] 类比标注了边界。
- [ ] 讲完有一道检查题，且先不给答案。

## 第 4 阶段：练习

检查：

- [ ] 一次一问。
- [ ] 我卡住时给三级提示，不直接给答案。
- [ ] 能迁移到新场景。

## 第 5 阶段：应用

二选一：

- **写代码**：做一个小项目，有验收标准。
- **读代码**：沿一条调用链画图，回答 3 个定位题。

检查：

- [ ] 有可演示/可复述的成果。
- [ ] 不是照抄教程。
- [ ] 能指出至少一个设计取舍或风险。

## 第 6 阶段：复习

检查：

- [ ] 有 1/3/7/14 天节点。
- [ ] 用主动回忆，不靠重读。
- [ ] 有错题记录与调整规则。

## 一次 45 分钟的学习节奏

| 时间 | 内容 |
|---|---|
| 0–5 分钟 | 回忆上次内容，回答 2 个问题 |
| 5–20 分钟 | 学一个新概念，记 3 个关键词 |
| 20–35 分钟 | 做 2–3 道题，允许卡住 |
| 35–42 分钟 | 对答案，写错因 |
| 42–45 分钟 | 用一句话复述，安排下次复习 |

## 常见失败

| 失败 | 后果 | 修法 |
|---|---|---|
| 跳过诊断 | 讲得太浅/太深 | 先做 8–12 题诊断 |
| 只看不练 | 假懂 | 每段讲解后必须有检查题 |
| 直接看答案 | 不会迁移 | 苏格拉底卡，先尝试 |
| 只学不用 | 很快忘 | 配小项目或源码阅读 |
| 不复习 | 两周归零 | 排 1/3/7/14 天节点 |
| 一次学太多 | 认知过载 | 一次一个概念，45 分钟 |
