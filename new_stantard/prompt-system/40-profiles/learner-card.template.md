# 学习者卡模板

> 用途：让 AI 知道你的基础、目标、时间与偏好，避免讲得太浅或太深。场景卡通过 `{{LEARNER_CARD}}` 引用。
> 原则：只写真实情况；不确定的写“待确认”，不要为了让 AI 高看一眼而夸大。
> 建议：每学期更新一次；换目标时复制新卡。

```markdown

- 专业/年级：
- 毕业时间：
- 当前主线：

## 已系统学习
- 编程语言：
- 后端/框架：
- 数据库：
- 计算机基础：
- 工具/工程：
- 项目经历：

## 碎片化/半懂
-

## 当前正在学
-

## 目标
- 短期（1–3 个月）：
- 中期（半年–1 年）：
- 长期（毕业前）：
- 目标类型：就业 / 考研 / 竞赛 / 兴趣（选一个主目标）

## 时间投入
- 每周可投入：
- 单次专注时长：
- 固定不可用时间：

## 学习偏好
- 更喜欢：讲解 / 例子 / 练习 / 项目 / 苏格拉底提问
- 不喜欢：

- 复盘频率：

## 已确认的偏好
- 语言：中文为主，保留英文术语
- 输出：先结论后细节
- 代码：要能运行，注明版本与命令

```

## 填写建议

- **已系统学习**只写真正学完一遍并有练习的；只看过视频不算“掌握”。
- **碎片化/半懂**很重要，AI 会据此决定是否补前置。
- **目标类型**只选一个主目标；多目标会让计划失焦。
- **时间投入**按真实可持续的时间写，不写“理论上每天 8 小时”。
- **薄弱点**写具体现象，例如“能背 TCP 状态，但解释不了 TIME_WAIT”，不要写“基础差”。

## 精简版

```text
身份：{{专业/年级}}
已学：{{语言/框架/基础课}}
项目：{{做过的项目}}
当前：{{正在学}}
目标：{{短期目标 + 类型}}
时间：{{每周小时}}
薄弱：{{具体卡点}}
偏好：{{讲解/练习/项目}}
```

## 隐私提醒

学习者卡不需要真实姓名、学校、学号、联系方式。用代号即可；这些信息对学习效果没有帮助。
