# 项目卡模板

> 用途：把“项目是什么样”固定下来，避免每次对话重复粘贴。场景卡通过 `{{PROJECT_CARD}}` 引用。
> 原则：只写与开发决策相关的信息；不写密钥、真实用户数据、生产地址。
> 建议：一个项目一张卡；跨项目时复制新卡。

## 填写建议

- **技术栈版本**必须写具体版本，例如 Java 17、Spring Boot 3.2.x、MySQL 8.0；不要只写“最新版”。
- **目录结构**控制在 15 行以内；只写本次可能改到的目录。
- **关键约定**比技术栈更重要：模型经常因为不知道分层和异常规范而写偏。
- **启动命令**不确定就写“待补充”，不要编造。
- **环境变量**只写名称和示例值，不写真实密码。

## 精简版（上下文窗口小）

```text
项目：{{一句话}}
栈：{{语言/框架/数据库/版本}}
结构：{{Controller/Service/Mapper/前端目录}}
约定：{{分层 + 异常 + 返回结构}}
任务相关：{{本次会改到的文件/表/接口}}
限制：{{不能改什么}}
```

## 使用方式

在场景卡中：

```text
【项目卡】
{{把本文件内容粘贴到这里，或只贴相关段落}}
```

长项目不必每次贴全卡；贴“技术栈 + 约定 + 本次相关文件”三段即可。
