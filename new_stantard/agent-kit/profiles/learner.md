## 二、已学完一轮（能看懂，会用）

- 语言：C++（STL 基础、指针引用）、Java SE（集合、异常、IO、多线程入门）
- 后端：SSM（Spring / SpringMVC / MyBatis）、Spring Boot
- 数据库：MySQL（CRUD、多表查询、基础索引）
- 基础：数据结构与算法、操作系统
- 工程：Git、Maven、Tomcat、Linux 常用命令

## 四、半懂（会用不会讲）

- Redis：缓存、简单分布式锁，没系统学过持久化和淘汰策略
- Docker：会 `build` / `run` / `compose up`，镜像分层、网络模式讲不清

## 五、明确的短板（重要）

1. **能读不能写**：看得懂别人代码，让自己从零写就不敢下手。
2. **会背不会讲**：名词能说出来，追问"为什么"就卡住。
3. **工程习惯弱**：很少写测试，日志随手 `System.out`，commit message 乱。
4. **调试靠猜**：出错先搜再猜，不会系统性地定位（看日志 → 缩小范围 → 二分）。

## 六、学习偏好

- 语言：中文为主，术语保留英文
- 结构：先结论后细节；先给图/表格，再给文字
- 讲解：要口语化，拒绝术语堆砌；每个概念说清"解决什么问题、不用会怎样"
- 代码：要能跑，带版本和命令，带逐行注释
- 练习：宁可少讲一个点，也要留一个必须自己动手的题
- 节奏：单次 45–90 分钟；连续两次讲同一主题容易走神

## 七、目标和时间（待你确认后填实）

- 长期目标：待定（就业 / 考研 / 竞赛 / 兴趣，先选一个主目标）
- 中期（半年到一年）：待定
- 短期（1–3 个月）：待定。可选：① 网络学透 ② 补 Redis/Docker ③ 给已有项目加缓存/测试/重构
- 每周可投入：待定
- 固定的不可用时间：待定

> 填写建议：先把"长期目标"钉死。目标不同，项目选型和学四大件的深度完全不一样——考研要的是做题和原理，就业要的是能跑的项目和八股，别两头都想要。

## 八、给你的默认假设

在目标确认之前，按以下假设工作，并在每次方案开头提醒我这些是假设：

1. 一期目标是**就业导向**，需要能写进简历的项目。
2. 每周可投入 **8–10 小时**，周末为主。
3. 项目规模：**单人、两周能出演示、一个月能上线**。
4. 技术栈：Java 17 + Spring Boot 3.x + MySQL 8 + Vue 3；Redis 只在真需要时加。
