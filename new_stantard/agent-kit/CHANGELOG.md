# CHANGELOG

## v0.2.0 — 2026-10-19

阶段卡从"写在 AGENTS.md 里的一段代码块"升级成**独立模板文件**，并补了原模板缺的四类信息。

新增 `templates/stage-card.md`：

- 完整版十节：一句话/完成标志 → 技术栈（含备选与代价）→ 原理（含"不用会怎样"）→ 架构（分层位置/数据流向/改动边界）→ 步骤（每步可观察结果）→ 语法（含常见错法）→ 实现（只给改动文件 + 怎么验证）→ 四大件映射（指回具体代码行）→ 坑（错误写法→现象→改法）→ 验收（能跑 + 能讲）→ 下一步。
- 精简版五节：改字段、加接口、修 bug 用。
- 使用规则六条 + 常见填错对照表。

`AGENTS.md`：

- §7 不再内嵌模板，改为"严格按 `docs/STAGE-TEMPLATE.md`"，并列出 6 条硬性要求（十节不许删、小改动用精简版、§1 不抄全栈、§6 只给改动文件、验收必须可执行、卡完等确认）。
- §6 六项要求重新对齐到模板节号，并把"技术栈"从"列名字"改成"讲为什么是它"。
- §8 增加一条：为填满栏目而编内容。

`SKILL.md` §10、`README.md` 目录结构与使用步骤同步。

设计取舍：模板本体放 `templates/`，项目里复制成 `docs/STAGE-TEMPLATE.md`。理由——`AGENTS.md` 每次会话都占上下文，必须保持短；模板会随迭代变长，属于按需读的东西。

## v0.1.1 — 2026-10-18

去具体化：把"个人博客"这个具体项目从所有文件里抽掉，改成可直接套用的通用描述与占位。

- `AGENTS.md` §1：项目经历改为"1 个 Spring Boot + Vue 前后端分离项目（CRUD、登录鉴权、部署上线）"，具体项目指向 `PROJECT.md`。常驻文件里不该出现某个具体项目的名字——换项目就得改一遍。
- `profiles/learner.md` §三：改成"项目经历表格"，字段是 项目类型 / 技术栈 / 做到什么程度 / 现在能讲清吗，留了新增行。
- `profiles/learner.md` §七：短期目标第 ③ 项由"深化博客项目"改为"给已有项目加缓存/测试/重构"。
- `README.md` / `CHANGELOG.md`：示例句去掉了具体项目名。

原则：**常驻层只写"我这类人是什么样"，档案层写"我这个项目是什么样"，示例层才写"比如某个具体项目"。** 三层混在一起，文件就不能复用了。

## v0.1.0 — 2026-10-18

首版。目标不是"设计完美"，而是**把 `prompt-system` 里需要手动粘贴的东西，变成 Agent 自动读取的仓库文件**。

新增：

- `AGENTS.md`：常驻约定。身份、语气、7 条硬契约、三轮协商模式、13 步流程骨架、二级阶段六要素与卡片模板。
- `skills/project-dev/SKILL.md`：13 步的逐条动作与验收、二级阶段切分判据、讲解六步法、四大件映射表、会话开场模板。
- `profiles/learner.md`：完整学习档案，补了"能读不能写""会背不会讲""调试靠猜"三条短板。
- `profiles/PROJECT.template.md`：项目卡，含当前阶段、代码约定、DoD。
- `README.md`：三种工具（Claude Code / Codex / DSH）的落地方式，`CLAUDE.md → @AGENTS.md` 一行引用法。

刻意没做：

- 没做 13 步各自的提示词全文。`prompt-system/20-dev/` 已经有一份更细的，重复没意义。

- 没填目标。长期目标是就业/考研还是竞赛，决定项目选型，等本人确认。
